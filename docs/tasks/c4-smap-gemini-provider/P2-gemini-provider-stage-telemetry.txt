STRUCTURED OUTPUT

Gemini and Local must emit the same P1 intermediate JSON semantics.

Use Gemini structured JSON output with a provider-compatible JSON Schema projection.

Gemini supports a subset of JSON Schema. If the P1 Dope schema contains keywords Gemini cannot accept:
- translate/strip only unsupported provider-schema keywords inside the Gemini adapter;
- keep shape/required/enums as strong as the provider supports;
- never weaken/remove the full Dope parser/validator;
- pass parsed Gemini output through the same `parseSynthesisStageResult` path used for Local.

A response accepted by Gemini's provider schema but rejected by Dope must fail closed.

Do not copy Gemini-native request/response/SDK types into `@dope/software-map`.

CAPABILITIES / BUDGETING

Expose Gemini capabilities through the existing provider-independent capability contract.

Keep context/input headroom provider-derived. Do not treat the large Gemini window as a fill target.

Avoid turning remote `countTokens` into a hot-loop call for every evidence-planner estimate. Use a safe bounded estimator for planning unless one bounded exact count is genuinely required. Actual response usage is the primary per-call telemetry source when Gemini reports it.

STAGE EXECUTION TELEMETRY

Introduce/complete a provider-independent stage execution envelope or equivalent that atomically returns model output plus normalized usage/size metadata.

Record at least:
- provider kind;
- provider model label;
- request bytes;
- output bytes;
- input tokens when available;
- output tokens when available;
- total tokens when available;
- token measurement source: `provider-reported`, `tokenizer`, `estimated`, or `unavailable`.

Dope orchestration/cache layer measures wall-clock call duration.

Cache reuse:
- must remain part of stage identity with provider/model;
- reused work records no new provider-call duration/token spend;
- telemetry must distinguish reused from fresh.

LOCAL TELEMETRY

- preserve no-project-evidence warm-up gate.

- malformed provider response;
- malformed stage JSON;
- timeout/cancellation.
