   - existing persisted review draft;

   - Add/Remove/Reparent/edit controls;

3. Add accepted Architecture mode.

   - show deterministic validation blockers;

4. Extend the Green initialized action row.

   Add:
   - **Edit Architecture**

   Clicking it opens or focuses the existing center editor.

   Repeated clicks must not create duplicate tabs/widgets.

5. Keep editor state independent.

   Editor owns its own:
   - selected boundary;
   - disclosure/expansion state if implemented;
   - scroll/focus;
   - dirty state;
   - save error/status.

   Do not use `controller.selectedId` as the editor selection.

   Prove a map/outline selection change can notify/re-render without replacing the editor-selected boundary or disclosure state.

6. Keep accepted edits draft-only.

   Typing, rename, purpose, canonical ID, roots, reparent, Add, Remove and dependency-constraint edits must only mutate the in-memory draft.

   No canonical service save call until **Save Architecture**.

7. Make all current canonical fields usable.

   Preserve current controls:
   - name;
   - purpose/responsibility;
   - parent;
   - canonical ID;
   - implementation roots;
   - Add System/Subsystem/Component;
   - Remove branch.

   For Subsystems carrying `allowedDependencies` / `forbiddenDependencies`, expose enough Advanced editing to preserve and repair those lists. Do not leave the developer with an invisible constraint that can block Save but cannot be fixed.

8. Accepted-mode presentation must not invent synthesis facts.

   Do not show synthesis confidence/rationale/open-question counts for canonical nodes unless that data truly exists from a pending review.

   Accepted mode may label developer-owned canonical Architecture clearly.

9. Save UX.

   Save Architecture:
   - disabled while deterministic blockers exist;
   - uses current expected fingerprint;
   - on success updates editor baseline/fingerprint from saved canonical state;
   - reports canonical save separately from resulting Software Map analysis status;
   - does not silently create history or close/reopen another tab.

10. Async/workspace guards.

   Workspace switch must supersede pending accepted Architecture load/save responses and clear project-local in-memory accepted draft/refinement UI state.

   Unsaved accepted edits must never leak into a newly attached project.
