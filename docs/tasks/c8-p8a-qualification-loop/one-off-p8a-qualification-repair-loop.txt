OFFICIAL CURRENT OAUTH CONTRACT TO VERIFY

Use current official OpenAI documentation during the live diagnosis. Do not rely on memory if current docs differ.

For the open-source ChatGPT-plan flow, verify at minimum:
- start the loopback callback listener before opening the browser;
- redirect URI uses HTTP 127.0.0.1, not localhost;
- keep scheme, host, and path identical; only the port may vary;
- use the exact same redirect URI, including port, in authorization and code exchange;
- initial registration uses client_id=dynamic_agent_client;

- require granted chatgpt.tokens.use.direct before plan inference;
- retain the verified account identity, issued client ID, stable host ID and protected token bundle for restart/refresh;
- serialize refresh for one session and atomically replace rotating access/refresh credentials;
- after token refresh, restart App Server with the new ACCESS_TOKEN, initialize it, and resume the saved thread using thread/resume.
