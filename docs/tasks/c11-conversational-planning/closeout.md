In the current product source, `RoadmapGreenfield.beginImplementationPlan()` exists and tests call it, but there is no production caller in `packages/theia-extension/src` or another product `packages/*/src` path. `ChatBackend` enables `planOnly` only when `chatImplementationPlan(...).planOnly` is already true. The visible Roadmap “Plan with Chat” setup binds the Chat to the older greenfield draft path.
