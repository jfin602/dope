No unconditional full npm test/check per prompt. Preserve source/authority hard stops, no speculative files/CI, precise T1/T2/T3, explicit manual closeout, no duplicated commands. UI changes use ADR 0016/0037. Ordinary T1 target <=8 minutes including focused checks, 10 soft/15 hard; T2/T3 justified exceptions.
