GOAL
Expose the stable Phase 8B single-task runtime in one small Dope workbench surface without pulling in phase sequences, WorkItems or Development Sessions.

PREFLIGHT
Read P1-P5 results, existing Theia widget/controller/contribution patterns, Dope Dark controls and AI Center role/model presentation.

IMPLEMENT
- Add an Agent Run controller/widget/contribution backed by the typed Agent Runtime service.

Focused controller/widget/source tests for command wiring, task creation, target display, grant-accept gating, start, real stop request, activity rendering, changed/validation/diff summaries, terminal/restart inspection, secret/raw-payload absence and accessible labels/status.

FINAL RESPONSE
