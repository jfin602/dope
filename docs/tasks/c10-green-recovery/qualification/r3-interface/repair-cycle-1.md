Relaunching the existing built Electron app **without** that override reached ready UI and completed every native Chat assertion. **Test-environment issue; no product repair.**
2. The first copied `.dope/roadmap.json` was rejected as `Corrupt or unsupported Roadmap index`. Its `projectRoot` still named `/home/jfin/dev/dope-p12-chat-replay`; `RoadmapStore.read` invokes `parseRoadmapIndex(..., root)`, which requires the current canonical root. This is the intended owner boundary for a relocated file, not a Chat failure. In the disposable copy only, the invalid owner was removed and the same `ROADMAP.md` was imported and accepted through the native UI as fresh Roadmap revision 1. The Roadmap and saved Chat then ran side by side. **Fixture-portability issue; no product repair.**

Ctrl+R left a live backend lease held by the previous renderer and initially denied restore. `ChatPanelController` explicitly retries after `claim.retryAfterMs`; `ChatRepository` keeps a live owner until release, process death, or its 60-second expiry. This protected the single-writer invariant and restored automatically. The full backend restart reclaimed its dead predecessor immediately. **Expected bounded lease behavior; no confirmed product defect.**
