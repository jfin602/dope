## D. Grounded touch-equivalent input

The product's React Flow gesture contract (`roadmapGestures`) supports one-finger pan, tap selection, pinch zoom, and node drag only when Arrange is enabled; pointer cancellation must leave a usable canvas. The host exposes an ELAN touchscreen, but its `/dev/input/event6` was not readable in this user session. Each **actual browser and Electron Chromium renderer** was therefore driven through DevTools `Emulation.setTouchEmulationEnabled` plus `Input.dispatchTouchEvent`. This is renderer input emulation, not `element.dispatchEvent` or ordinary mouse input, and **does not prove physical device hardware/driver behavior**.

[Event and geometry trace](repair-cycle-3/evidence/touch-emulation.json) records trusted `pointerdown/move/up`, `touchstart/move/end`, and `pointercancel`/`touchcancel` on the actual canvas. In each shell, one touch panned the camera **+112,+56**; two touch points zoomed up to scale 2. The stable [follow-up](repair-cycle-3/evidence/touch-followup.json) repeated Fit at ~0.2 and pinch to ~0.8, then touch-tapped Phase 8 from Phase 9 selection and observed matching details. A touch Arrange drag moved Phase 10's card about **+60,+36** with a stable camera in both renderers. Cancellation left the canvas interactive. All required supported gesture paths: **PASS** with this stated emulation limit.
