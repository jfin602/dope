## Source, actors and repaired defect

The only product delta from Group 1's `00121646f6b5f3d66e06e3cd320935a76dc73353` is [untrusted Chat/AgentRun Markdown rendering](../../../../../packages/theia-extension/src/browser/untrusted-message-markdown.ts) and its focused regression test, committed separately as `9186110`. Dope backend, model registry, Chat RPC, proposal/approval, Roadmap persistence, R2 and Group 1 authority seams are byte-identical. Current browser bundle SHA-256 is `4d2db992e40f492c8f2f09c6c4215debb1c43ed562aeb36f277c6aaf5836c664`. The browser backend was rebuilt and restarted as PID `74341` on `127.0.0.1:3000`; LM Studio PID `22774` remained on `127.0.0.1:1234`. Its live loaded model inventory reported the exact Q4_K_M GGUF, context length 32768 and parallel 4. No global model/role default changed.

The source audit found a real browser egress defect: Theia's Markdown renderer turns an untrusted model-authored `![alt](url)` into an image element before returning the detached fragment; the old wrapper filtered clickable links but did not stop automatic remote image loads. The repair installs an `img-src 'self' data: blob:` policy **before** invoking that renderer and replaces rendered images with text. This applies to shared Chat and AgentRun untrusted prose. A disposable plain Chat on the rebuilt browser returned a controlled Markdown image pointing at a separate loopback receiver (`127.0.0.2:8765`). The UI displayed `[Image omitted: sample]`, the policy appeared in the document, zero image elements remained, and the receiver observed **zero HTTP requests**. The tab asset inventory listed the image URL as an *attempted resource*; it is not reported as a delivered request. Focused Chat presentation tests passed **8/8**; extension and browser builds completed with zero errors. A separately tried Work transcript test had one failure (`0` rather than `31` entries); its cause was not diagnosed, and neither it nor a full aggregate is claimed as passing in this R4 gate. R6 owns aggregate reconciliation.
