## Work transcript failure

The recorded `0 !== 31` reproduced before edits with `node --test test/unit/work-transcript-presentation.test.ts`. It was a **pre-existing incomplete test fixture**, not a Work pagination or product defect. `WorkSelectionController.select` reads steering, actions and map impact in parallel before `readTranscript`. This test's fake `AgentRuntimeService` omitted all three methods, so a `TypeError` entered the controller's honest “Work detail could not be read” path before cursor 0. The test was introduced in `6eee315`; the controller's `readSteering` path was added in `96c1497` without updating this fixture. The failure predates R4's `9186110` renderer change. The controller source was unchanged, and rebuilding the extension did not explain or repair it.

Product commit `715066e` adds the missing read-only fixture methods, asserts a clean detail state, every cursor from 0 through 30, final message and truncation state, and checks that a late transcript page cannot repopulate a cleared selection. The adjacent real `AgentStore` integration still reopens more than one page from the beginning. No Work product logic or pagination assertion was weakened.

## Remote image security and browser effects

The R4 repair placed `img-src 'self' data: blob:` in a document-wide dynamic CSP before Theia rendered each untrusted message. That policy applied to unrelated main-document images after the first Chat or AgentRun render, so its scope was excessive even though it blocked the demonstrated model-authored image request. Product commit `715066e` removes the document policy. The shared Chat/AgentRun renderer now uses Markdown with HTML disabled and an image-token rule that emits escaped placeholder text **before DOM creation**. DOMPurify additionally forbids media tags and source attributes when constructing the returned fragment. Link destination validation remains. The protected output omits remote, same-origin and data image tokens alike; no remote-image egress is restored.

The final rebuilt Codex-browser Dope tab `5` displayed the saved Q4-authored `![sample](http://127.0.0.2:8765/pixel)` reply as `[Image omitted: sample]`. A disposable saved AgentRun displayed bold prose, a normal link and `[Image omitted: agent sample]` for `http://127.0.0.2:8765/agent-pixel`. Read-only DOM inspection found **zero** message images and **zero** document CSP meta elements after both surfaces rendered. A separate loopback receiver on `127.0.0.2:8765` saw **no `/pixel` or `/agent-pixel` request**; Codex-browser control tab `6` reached that same receiver at `/control` (and fetched `/favicon.ico`), proving the endpoint was live. The Dope response also had no CSP header. The final frontend bundle SHA-256 was `fbc43e4dfb31c38c6b963fa3390497b2f76e3c06af0db852b472539168299695`.

A disposable external-image Markdown preview was opened as an unrelated application surface, but its webview stayed blank in this Codex-browser setup; it is **not** recorded as a successful image-display test. The removed document policy can no longer globally block that or other main-document images. The browser directly showed that Chat, Work selection, AgentRun center transcript, editor and project explorer remained usable. This investigation does not qualify native Electron or whole-host egress.

Focused validation on the repaired product: extension build and browser build passed; 64/64 tests passed across Work transcript, Work selection/integration, AgentRun UI, Chat presentation/panel and Roadmap Chat panel/actions. The source-level image regression cases cover inline, nested and reference images plus escaped raw HTML. `git diff --check` passed. **The full `npm run check` was not run.**
