# P3-B reduced core qualification contract — 2026-11-01 owner decision

This is the authoritative **forward** P3-B core qualification contract. It replaces the exhaustive H3 action-by-action live replay matrix for future P3-B qualification. Historical H3, P2 and P3-B reports retain their original results. The reduced evidence burden does not change schema-2 validation, source and project authority, lease and revision checks, human approval, atomicity, or no-write guarantees.

| Gate | Required evidence |
| --- | --- |
| Q1 — Action correctness | Deterministic validation of all 19 supported Phase, Gate, Criterion and Correction actions, 1–3 action atomicity, before/after projection, rejection and approval. One protected connected-Chrome multi-action approval and Gate reparent approval, combined when the model can produce them. |
| Q2 — Authority and proposal lifecycle | Deterministic stale source/revision, lease, project and replacement negatives; one connected-Chrome invalidation workflow. |
| Q3 — Protected skill and selective context | Current-turn verified `/roadmap` invocation, unskilled denial and complete required context; one large 16K fixture. |
| Q4 — Chat/Roadmap UI integrity | One connected-Chrome narrow-layout, keyboard and provisional-preview smoke. Deterministic camera persistence, reduced motion and related isolated coverage. |

Individual live Accept/Reject for every typed action, a live three-action replay when atomicity is deterministic, separate browser replay of every terminal card state, exhaustive viewport/animation testing, repeated model latency benchmarks, generic P2 output-limit/clipboard/reconnect qualification and native Electron GUI parity are **not mandatory** for P3-B Core GREEN. They remain broader product concerns where applicable. Unsupported linked-source structural actions still fail closed; no skill text grants write authority.

P3-B Core GREEN requires Q1–Q4 GREEN on applicable final source. It does not retroactively qualify H3, P2, C12 or Phase 12. Each gate receives its own exact-source report; Q1 alone cannot close P3-B.
