IMPLEMENTATION

1. Replace the current stacked map chrome with a shared canvas-first shell.

   Current normal-flow structure includes header, planningBar, workPanel, flowBar, flowPanel, breadcrumbs, status, then canvas.

   Refactor toward one compact toolbar plus a flex/grid canvas stage so the React Flow canvas consumes all remaining center-tab space.

   The exact component extraction is implementation-owned.

2. Establish one Dope-owned map toolbar.

   Consolidate genuinely map-global controls, including where applicable:
   - Planning Map toggle;
   - Architecture / Flow mode;
   - Up;
   - Focus;
   - Open selected tab;
   - Open source;
   - Fit;
   - node color;
   - Flow trace downstream/upstream/clear;
   - Planning-map-global view/selection controls.

   Do not move rich selected edge/work/evidence details into the toolbar.

3. Remove the duplicate React Flow Controls cluster.

   The widget currently renders React Flow `Controls` in addition to Dope controls.

   Route required geometric map controls through the Dope toolbar using the existing `ReactFlowInstance`:
   - zoom in;
   - zoom out;
   - fit current architecture/map context.

   Preserve `MapViewport` semantic zoom behavior and fitted baseline.

4. Preserve fit/no-snap semantics.

   Structural rerenders and toolbar changes must not introduce extra `fitView` calls.

   Preserve:
   - `mapFitContext`;
   - `fitRequested`;
   - semantic LOD no-snap behavior;
   - focus/up/explicit-fit semantics.

   Toolbar zoom is geometric only. It must not focus nodes or mutate map/domain state.

5. Compact orientation/status.

   Breadcrumbs must remain complete and identity-based but should not remain a large independent row if that reduces canvas area.

   Prefer integrating breadcrumbs into the toolbar or a compact canvas overlay/rail.

   Preserve the accessible status live region. Its visible form may become a small floating status affordance instead of a permanent full-width row.

6. Prepare the canvas stage for P2 overlays.

   P1 does not need to implement the final inspection overlay, but the shell must make it possible for details to float without sizing the canvas.

   Avoid fixed heights tied to Flow/Planning detail content.

7. Preserve all mode behavior.

   Architecture:
   - normal map projection;
   - focus/up/fit;
   - source/open-tab/color.

   Flow:
   - current query/result;
   - tracing;
   - node/edge selection;
   - edge inspection state.

   Planning:
   - current controller/mode semantics;
   - Current/Target/Diff and edit behavior.
